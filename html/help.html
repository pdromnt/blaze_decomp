【動作環境】
　Windows95・98・NT・2000
　Pentium120MHz以上
　要DirectX

・起動時には他のソフトを終了して下さい
・特定の機種でフルスクリーン３・４が対応してない場合があります。
　その場合は　Blaze_screen5.bat　を実行してください
▲▼　操作　▲▼
[Z]連射通常弾（敵の弾を相殺できます）
[Z]押しっぱなし特殊武器（アイテムが無い場合バルカン）
[X]押しっぱなしダッシュ（バックファイヤーも武器になります）
[X]ダブルクリックリング（MODE03は武器切替）
[Z][X]同時メガクラッシュ（面ごとに３回まで）
[Z][X]押さないシールド回復（MODE 02以外）
[矢印]移動
▲▼　遊び方　▲▼
MODE 00敵を倒すとアイテムがでます。アイテムを取ると自機の下にエネルギー残量が表示され、無くなるまで特殊攻撃が出来ます。
MODE 01始めに特殊武器を選択ます。エネルギーは徐々に回復しますが、使い切るとチャージの間使用できなくなります。
MODE 02特殊武器のリミットがありません。ガンガン撃って構いませんが、シールドは回復しません。（上級者向け）
MODE 03特殊武器を切替できます。[X]ダブルクリックで選択します
OPTIONゲームの設定をします
GAME LEVEL：難易度を設定します
SCREEN MODE：スクリーンモードを設定します。３番のモードがベストですが、動かない場合他のモードを試して下さい。 フルスクリーン５は重くなりますがたいていの機種で動作します。
EXITゲームを終了します
スコア敵を倒すとスコアが加算されます。早く倒せば多く点数が入ります。また、敵を残さず殲滅すると、ボーナスが加算されます。
ホームページ上でランキング発表しています。
